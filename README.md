# Xray4all

## 首次启动

解压后进入个人目录，运行：

```bash
./run.sh
```

需要订阅且尚未保存链接时，在终端提示处粘贴自己的订阅链接并按回车。输入不会显示，脚本会自动保存到 `subscription`。

脚本会先尝试已有节点。没有节点或已有节点无法启动并通过代理验证时，才拉取订阅并重试。验证通过后会自动进入启用代理的 Bash，可以直接运行 `curl`、`git` 等命令。输入 `exit` 可返回原来的终端，Xray 会继续在后台运行。

没有订阅时，可以将节点链接直接填入 `nodes.txt`，每行一个，并移除空的 `subscription` 文件。

## 端口

默认端口为 `32808`（SOCKS）和 `32809`（HTTP）。同机端口冲突时，在个人副本里修改 `ports.env`，再运行 `bash run.sh`。
